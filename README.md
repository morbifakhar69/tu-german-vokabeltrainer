# TU German Vokabeltrainer

A small command-line spaced-repetition flashcard app for learning German
vocabulary, built for the final project of my Python programming course.

Work in progress - see the sections below for what's already implemented.

## Why

International students at TU Dortmund (and elsewhere) often need to pick up
German vocabulary quickly, but most flashcard apps are either overkill (Anki)
or don't track *what* you actually struggle with. This is a small, personal
version: a CSV of words in, spaced-repetition scheduling, filtering by topic,
and a couple of stats/plots to see how you're doing.

More details, install instructions and usage examples will be added as the
project progresses.
